## Mistakes I Made

- Initially I confused text inside quotation marks
  with variables in an f-string.
- I initially changed "25" directly to 25 instead
  of practicing type conversion.

## What I Learned From My Mistakes

Variables need to be referenced correctly inside
an f-string using {variable}.

Type conversion changes the data type of a value
using functions such as int() and float().
